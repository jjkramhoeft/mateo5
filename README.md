# Mateo 5 år 🎁

A birthday card and small game for Mateo's 5th birthday, in one self-contained HTML file ([index.html](index.html)).

**▶ Open the card: https://jjkramhoeft.github.io/mateo5/**

Tap the card to open it, then play the present game: walk Mateo around with the arrow keys or WASD, or by tapping on a phone, and open all five presents.

## How it was made

The page was made by chatting with Claude (Opus 5.5) in Claude Code. It started from this prompt:

> I want to make a self contained html page/game/birthday card for my nephew Mateo's fire year birth day.
> The Page should look like a birthday card and on any click it should open with some animation, then a play gam button should be visible, when clicked a easy game about opening presents should be playable by only moving (asdw or arrows). my nephew Mateo is turning 5, he is a boy and have a short affro

Follow-up requests translated all text to Danish, changed the signature and one line of the message, and added tap-to-walk so the game works on phones.

Everything is drawn in code, including Mateo, the presents, the confetti and the "Happy Birthday" melody. The page uses no images, libraries or internet connection.
